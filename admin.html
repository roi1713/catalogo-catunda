Entrar

Para editar, este painel precisa de uma chave de acesso do GitHub (uma vez só por aparelho; ela fica guardada neste navegador).

  1. Logado no GitHub como roi1713, abra github.com/settings/personal-access-tokens/new.
  2. Nome: Painel Catunda. Validade: a mais longa que quiser.
  3. Em Repository access escolha Only select repositories e marque catalogo-catunda.
  4. Em Permissions → Repository permissions, ponha Contents em Read and write.
  5. Clique em Generate token, copie o texto que começa com github_pat_ e cole abaixo.

A chave só dá acesso a este repositório. Não use este painel em aparelho que não seja seu.
